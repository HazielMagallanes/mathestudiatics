| Concept                   | Formula                                                                                   |
| ------------------------- | ----------------------------------------------------------------------------------------- |
| Vector between two points | $\vec{AB} = B - A$                                                                        |
| Sum                       | $\vec{u} + \vec{v} = \left(u_x + v_x,\; u_y + v_y\right)$                                 |
| Scalar multiple           | $k\vec{u} = \left(ku_x,\; ku_y\right)$                                                    |
| Norm                      | $\left\|\vec{u}\right\| = \sqrt{u_x^2 + u_y^2 + u_z^2}$                                   |
| Unit vector               | $\hat{u} = \frac{\vec{u}}{\left\|\vec{u}\right\|}$                                        |
| Dot product               | $\vec{u} \cdot \vec{v} = u_xv_x + u_yv_y + u_zv_z$                                        |
| Angle between vectors     | $\cos\theta = \frac{\vec{u} \cdot \vec{v}}{\left\|\vec{u}\right\|\left\|\vec{v}\right\|}$ |
| Distance between points   | $d(A, B) = \left\|\vec{AB}\right\|$                                                       |

## Conditions

| Property              | Condition                       |
| --------------------- | ------------------------------- |
| Orthogonal            | $\vec{u} \cdot \vec{v} = 0$     |
| Parallel              | $\vec{v} = k\vec{u}$            |
| Parallel in the plane | $u_xv_y - u_yv_x = 0$           |
| Same direction        | $k > 0$ in $\vec{v} = k\vec{u}$ |

## Components from magnitude and direction

$$
v_x = \left|\vec{v}\right|\cos\theta, \qquad
v_y = \left\|\vec{v}\right\|\sin\theta
$$

## Properties of the dot product

$$\vec{u} \cdot \vec{v} = \vec{v} \cdot \vec{u}$$

$$
\vec{u} \cdot \left(\vec{v} + \vec{w}\right) =
\vec{u} \cdot \vec{v} + \vec{u} \cdot \vec{w}
$$

$$\left\|\vec{u}\right\|^2 = \vec{u} \cdot \vec{u}$$
