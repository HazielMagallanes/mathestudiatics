| Concepto                | Fórmula                                                                                   |
| ----------------------- | ----------------------------------------------------------------------------------------- |
| Vector entre dos puntos | $\vec{AB} = B - A$                                                                        |
| Suma                    | $\vec{u} + \vec{v} = \left(u_x + v_x,\; u_y + v_y\right)$                                 |
| Producto por escalar    | $k\vec{u} = \left(ku_x,\; ku_y\right)$                                                    |
| Norma                   | $\left\|\vec{u}\right\| = \sqrt{u_x^2 + u_y^2 + u_z^2}$                                   |
| Vector unitario         | $\hat{u} = \frac{\vec{u}}{\left\|\vec{u}\right\|}$                                        |
| Producto escalar        | $\vec{u} \cdot \vec{v} = u_xv_x + u_yv_y + u_zv_z$                                        |
| Ángulo entre vectores   | $\cos\theta = \frac{\vec{u} \cdot \vec{v}}{\left\|\vec{u}\right\|\left\|\vec{v}\right\|}$ |
| Distancia entre puntos  | $d(A, B) = \left\|\vec{AB}\right\|$                                                       |

## Condiciones

| Propiedad             | Condición                       |
| --------------------- | ------------------------------- |
| Ortogonales           | $\vec{u} \cdot \vec{v} = 0$     |
| Paralelos             | $\vec{v} = k\vec{u}$            |
| Paralelos en el plano | $u_xv_y - u_yv_x = 0$           |
| Mismo sentido         | $k > 0$ en $\vec{v} = k\vec{u}$ |

## Componentes a partir de módulo y dirección

$$ v_x = \left|\vec{v}\right|\cos\theta, \qquad
v_y = \left\|\vec{v}\right\|\sin\theta$$

## Propiedades del producto escalar

$$\vec{u} \cdot \vec{v} = \vec{v} \cdot \vec{u}$$

$$\vec{u} \cdot \left(\vec{v} + \vec{w}\right) =
\vec{u} \cdot \vec{v} + \vec{u} \cdot \vec{w}$$

$$\left\|\vec{u}\right\|^2 = \vec{u} \cdot \vec{u}$$
