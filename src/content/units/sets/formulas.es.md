| Concepto             | Notación         |
| -------------------- | ---------------- |
| Pertenencia          | $x \in A$        |
| Inclusión            | $A \subseteq B$  |
| Inclusión estricta   | $A \subset B$    |
| Conjunto vacío       | $\varnothing$    |
| Conjunto de partes   | $\mathcal{P}(A)$ |
| Unión                | $A \cup B$       |
| Intersección         | $A \cap B$       |
| Diferencia           | $A \setminus B$  |
| Complemento          | $A^c$            |
| Diferencia simétrica | $A \triangle B$  |
| Cardinalidad         | $\left           | A\right | $   |

## Cantidad de subconjuntos

$$\left|\mathcal{P}(A)\right| = 2^n, \qquad \text{subconjuntos propios} = 2^n - 1$$

## Inclusión-exclusión

$$\left|A \cup B\right| = \left|A\right| + \left|B\right| - \left|A \cap B\right|$$

## Intervalos

| Intervalo                 | Desigualdad     |
| ------------------------- | --------------- |
| $\left[a, b\right]$       | $a \le x \le b$ |
| $\left(a, b\right)$       | $a < x < b$     |
| $\left[a, b\right)$       | $a \le x < b$   |
| $\left[a, +\infty\right)$ | $x \ge a$       |
| $\left(-\infty, b\right]$ | $x \le b$       |

## Propiedades de las operaciones

$$A \cup B = B \cup A, \qquad A \cap B = B \cap A$$

$$A \cup \varnothing = A, \qquad A \cap \varnothing = \varnothing$$

$$
\left(A \cup B\right)^c = A^c \cap B^c, \qquad
\left(A \cap B\right)^c = A^c \cup B^c
$$
