| Tema                       | Fórmula                                                |
| -------------------------- | ------------------------------------------------------ |
| Suma y resta de fracciones | $\frac{a}{b} \pm \frac{c}{d} = \frac{ad \pm cb}{bd}$   |
| Producto de fracciones     | $\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}$        |
| Cociente de fracciones     | $\frac{a}{b} : \frac{c}{d} = \frac{ad}{bc}$            |
| Exponente negativo         | $a^{-n} = \frac{1}{a^n}$                               |
| Exponente fraccionario     | $a^{m/n} = \sqrt[n]{a^m}$                              |
| Producto de potencias      | $a^m \cdot a^n = a^{m+n}$                              |
| Cociente de potencias      | $a^m : a^n = a^{m-n}$                                  |
| Potencia de potencia       | $\left(a^m\right)^n = a^{mn}$                          |
| Raíz de un producto        | $\sqrt{a \cdot b} = \sqrt{a} \cdot \sqrt{b}$           |
| Extraer cuadrados          | $\sqrt{k^2 \cdot m} = k\sqrt{m}$                       |
| Definición de logaritmo    | $\log_b a = c \iff b^c = a$                            |
| Logaritmo de un producto   | $\log_b(xy) = \log_b x + \log_b y$                     |
| Logaritmo de un cociente   | $\log_b\left(\frac{x}{y}\right) = \log_b x - \log_b y$ |
| Logaritmo de una potencia  | $\log_b\left(x^n\right) = n\log_b x$                   |
| Cambio de base             | $\log_b x = \frac{\ln x}{\ln b}$                       |
| Intervalo cerrado          | $\left[a, b\right]$                                    |
| Intervalo abierto          | $\left(a, b\right)$                                    |
| Semirrecta                 | $\left[a, +\infty\right)$                              |
