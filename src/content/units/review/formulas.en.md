| Topic                            | Formula                                                |
| -------------------------------- | ------------------------------------------------------ |
| Adding and subtracting fractions | $\frac{a}{b} \pm \frac{c}{d} = \frac{ad \pm cb}{bd}$   |
| Multiplying fractions            | $\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}$        |
| Dividing fractions               | $\frac{a}{b} : \frac{c}{d} = \frac{ad}{bc}$            |
| Negative exponent                | $a^{-n} = \frac{1}{a^n}$                               |
| Fractional exponent              | $a^{m/n} = \sqrt[n]{a^m}$                              |
| Product of powers                | $a^m \cdot a^n = a^{m+n}$                              |
| Quotient of powers               | $a^m : a^n = a^{m-n}$                                  |
| Power of a power                 | $\left(a^m\right)^n = a^{mn}$                          |
| Root of a product                | $\sqrt{a \cdot b} = \sqrt{a} \cdot \sqrt{b}$           |
| Extracting squares               | $\sqrt{k^2 \cdot m} = k\sqrt{m}$                       |
| Definition of logarithm          | $\log_b a = c \iff b^c = a$                            |
| Logarithm of a product           | $\log_b(xy) = \log_b x + \log_b y$                     |
| Logarithm of a quotient          | $\log_b\left(\frac{x}{y}\right) = \log_b x - \log_b y$ |
| Logarithm of a power             | $\log_b\left(x^n\right) = n\log_b x$                   |
| Change of base                   | $\log_b x = \frac{\ln x}{\ln b}$                       |
| Closed interval                  | $\left[a, b\right]$                                    |
| Open interval                    | $\left(a, b\right)$                                    |
| Half-line                        | $\left[a, +\infty\right)$                              |
